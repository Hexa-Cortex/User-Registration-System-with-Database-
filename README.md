🚀 User Registration System with Database

A full-stack mini project that demonstrates how to build a simple and efficient user registration system using modern web technologies. This project allows users to register through a form and securely stores their data in a database.

---

📌 Project Overview

This project is designed to help beginners understand the complete flow of frontend → backend → database integration.

Users can:

- Enter their details using a registration form
- Submit the form
- Have their data stored in a database

This project is perfect for students learning full-stack development and looking to build a strong foundation.

---

✨ Features

- 🧾 Clean and responsive user registration form
- 🔗 Seamless frontend-backend integration
- 💾 Data stored in MongoDB database
- ⚡ Fast and lightweight Node.js backend
- 📁 Organized folder structure
- 🧑‍💻 Beginner-friendly code

---

🛠️ Tech Stack

Frontend:

- HTML5
- CSS3

Backend:

- Node.js
- Express.js

Database:

- MongoDB (Mongoose ODM)

⚙️ Installation & Setup

Follow these steps to run the project locally:

1️⃣ Clone the Repository

git clone https://github.com/your-username/user-registration.git

2️⃣ Navigate to Project Folder

cd user-registration

3️⃣ Install Dependencies

npm install

4️⃣ Start MongoDB

Make sure MongoDB is running locally:

mongod

5️⃣ Run the Server

node server.js

6️⃣ Open in Browser

Visit:

http://localhost:3000

🔄 Workflow Explanation

1. User enters details in the form
2. Form sends POST request to server
3. Server processes request using Express
4. Data is saved in MongoDB using Mongoose
5. Success message is returned to user
